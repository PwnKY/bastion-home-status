# 前端视觉与边界说明（DESIGN）

记录当前实现。此次重设计解决旧版辅助字只有 8–11px、窄栏服务表拥挤、拓扑与摘要争抢注意力的问题；不改检测、历史、认证或网络配置。

## 黑色视觉与可读性

- 黑色底 `--bg #0d0f11`，侧栏 `#0a0c0d`，面板 `#15191d`，抬升面 `#1b2025`，悬停 `#20262b`。
- 描边 `#30363c`、弱分隔 `#252c32`；层级靠明度、间距和 1px 边框，不使用发光、渐变或模糊玻璃。
- 正文 16px，服务名 15px，辅助文字至少 13px；桌面标题 36px，手机标题 29px，测量数字 29–38px。窄屏重排内容，不缩小辅助字号。
- 文字 `#eef0f2`、次级 `#bac2ca`、辅助 `#a3adb7` / `#9aa4ae`。健康绿 `#a4d2b0`、关注琥珀 `#e1b879`、故障红 `#e79b9b`、维护蓝 `#a6bfd9` 克制使用。
- 所有文字与状态颜色令牌在基础表面上满足普通文字 4.5:1 对比度，单测防止字号和颜色回退。实际浏览器另检查可见文字计算字号。
- 系统字体、等宽数字 `tabular-nums`、内联 SVG 图标、本地 favicon；不加载外部字体、CDN 或 MCP。
- CSS 使用 `@layer reset, base, layout, components, responsive`，令牌集中在 `:root`。

## 总览的信息顺序

1. **三项摘要**：当前概况、当前观测覆盖、独立采集来源新鲜度。单项异常不表述成整个家庭断网，未知不计作已确认故障。
2. **关注快捷入口**：故障、降级、未知分别进入服务页筛选。
3. **出口观测**：IPv4 / IPv6 横向分区，每个测量显示自己的标签、数值和状态。没有基准配置时不构造探针。
4. **关键观测**：跨分组关注优先、最多六项；宽幅服务表，完整列表仍保持后端顺序，放在服务页，支持搜索、分组、状态筛选。
5. **回家链路**：仅保留控制、数据、隧道三项独立摘要。完整结构示意放在连接路径页，以 HTML 节点呈现，避免 SVG 缩放造成小字。
6. **独立历史、最近事件**：单独宽幅区块，不再把它们挤进服务表旁边的窄栏。
7. **来源明细与检测边界**：来源默认折叠，展开后显示独立心跳；刷新保留展开状态。

DNS、ICMP、HTTPS 各自计量，不混合历史、不互相覆盖故障。配置 `ipv6-icmp` 后 IPv6 卡明确显示 Ping；即使失败也不回退到 DNS。原 DNS 53 端口观测仍在完整列表及历史中。趋势图仍是独立 IPv4 HTTPS 历史，不变成 Ping 曲线。

## 布局与响应式

216px 固定侧栏，内容最大 1480px。总览纵向宽幅分区，出口两列；连接路径页可使用两列。

| 断点 | 行为 |
| --- | --- |
| `max-width: 1120px` | 收紧留白，连接路径页单列，服务表重排列宽，不缩小文字 |
| `max-width: 900px` | 侧栏变抽屉，显示菜单按钮与遮罩；主区取消左边距；链路摘要单列 |
| `max-width: 720px` | 主概况占整行，另外两项摘要并列；出口及事件单列；服务表隐藏历史小条，完整历史仍可在详情查看 |
| `max-width: 500px` | 服务条目两行重排，名称和范围在上，状态与数值在下；筛选器单列；详情单列 |
| `prefers-reduced-motion: reduce` | 去除按压位移，过渡时长降至 0.01ms |

最窄 320px。测试覆盖 1440 / 1024 / 768 / 390 / 320px 四页及 720px 的 200% 缩放等效重排；不能把这种视口测试冒充真实设备或浏览器缩放操作。

## 交互、移动端与可访问性

- 顶部跳转链接、主区路由焦点、导航 `aria-current`、分组及分段 `aria-pressed`、可见 2px 聚焦环、实时提示 `role=status`。
- 状态同时提供文字和颜色；图表与结构示意提供描述，结构示意明确不等于逐节点路由验证。
- 原生 `dialog` 支持 Esc、遮罩关闭；刷新保持详情、服务按钮、搜索焦点及光标位置。若恢复项退出六项预览，关闭详情回到主内容，不把焦点留在不存在的按钮上。
- 鼠标悬停限定 `(hover: hover) and (pointer: fine)`；输入和选择框 16px，操作控件至少 44px，允许缩放。
- `viewport-fit=cover` / `interactive-widget=resizes-content`、安全区、`100dvh`、滚动边界和背景滚动锁保留。真实手机键盘、安全区、粘滞悬停与手感仍需实机确认。
- 仅指针按压小控件 `scale(.97)` / 160ms / `cubic-bezier(0.23, 1, 0.32, 1)`；列表、图表、状态不做位移动画；键盘没有动画。
- API 实时、演示、加载、接口失联标识独立；状态色即时更新，没有闪烁或逐数值动画。

## 真实数据边界

1. 默认读取同域版本化 API，演示仅限显式演示构建；生产不接受 `?demo=1`。
2. 后端负责状态确认、事件及补传；展示只做独立新鲜度保护，不改变检测结果。
3. 年龄采用服务器时间加单调 elapsed；过期撤销当前测量，保留历史参考。来源新鲜不等于业务正常。
4. 七天读取独立历史，缺点保留未知，曲线断线，不借用 24h 样本或连过缺口。
5. 路径和连接数取结构化字段，不从降级推断中继，不写死连接数量。
6. 浏览器只访问同域只读摘要，无设备管理接口或采集凭据；浏览器登录和采集认证独立。

基础可达不代表播放、转码、下载、完整路由或控制同步。未知是缺少新鲜证据，不是故障的另一种说法。
