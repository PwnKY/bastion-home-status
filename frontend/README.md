# Bastion 前端

Vite + 原生 ES modules/CSS，无 React、外部字体或 CDN。黑色 / 炭灰视觉保持不变。

默认使用同域 `/api/v1/status` 的真实摘要。浏览器不保存采集凭据、不访问设备接口。API 失败后保留历史，当前状态变未知，不回退合成数据。

## 使用

```bash
npm ci
npm run dev          # 真实 API 模式；无后端就显示未知
npm run build        # 生产构建，禁用演示模式
npm run preview
npm test
npm run check:ui     # 明确的合成视觉检查，结束后重建生产版本
npm run check:live   # 本机 Go/SQLite 与 Chrome 集成；生成测试输入，不访问家庭
```

开发/预览进程可设置 `BASTION_DEV_API=http://127.0.0.1:18080` 代理本机后端。该环境变量仅在 Vite 服务器使用，不进入浏览器代码。生产由 Caddy 同域代理。

视觉演示使用 `npm run dev:demo`，访问 `http://127.0.0.1:5173/?demo=1`；只有显式演示构建可使用场景选择器。普通生产构建即使添加 `?demo=1` 也不会启用演示。

需要 Node 22+；集成检查另需 Go 1.26.9+ 和本机 Chrome。设置 `CHROME_PATH` 可指定浏览器。测试使用隔离的临时 profile，不使用 MCP 或个人登录会话。

## 数据与展示

- `src/api.js`：版本/枚举验证、无数据空壳、API 获取与服务器时间 + 单调时钟基准。
- `src/model.js`：纯派生视图，源与检测项独立有效期、过期保护、历史/当前延迟分离。
- `src/main.js`：哈希路由、渲染、筛选、原生详情、焦点恢复和 10 秒轮询。
- `src/presentation.js`：纯展示筛选、最多 8 项的总览优先级和带单位测量格式；不改检测结论。
- `src/trend.js`：历史缺口分段，不画不存在的连续折线。
- `src/data.js`：公共服务目录和显式演示数据；不是生产 fallback。

四个路由：`#overview`、`#services`、`#paths`、`#events`。

真实模式的连接数和路径模式来自结构化字段，不从 `degraded` 推断 DERP，也不硬编码就绪连接数。拓扑是结构示意，不代表逐节点验证完成。

24h 历史为 48 个半小时窗口点，7d 为独立端点的 336 个窗口点。上线前或失联期间保留未知；百分比仅统计已测窗口点，覆盖率另列，不是完整时间加权 SLA。

完整字段与源判定见 [协议](../docs/protocol.md)。运行模板见 [部署说明](../docs/runtime.md)。

## 验收

- 单元检查：数据契约、API 缺失、源新鲜度、时钟偏差、统计分母、SVG 缺口、公开内容守卫。
- 演示 Chrome 检查：54 项交互、五种宽度、键盘、减少动效、触摸能力、控件尺寸与过期语义。
- 真实 API Chrome 检查：61 项生成的检测夹具、8 个独立来源凭据，覆盖认证上报、SQLite、独立 DNS/ICMP/HTTPS 结果、ICMP 失败不回退 DNS、关注筛选、焦点恢复、来源展开、历史、中断/恢复与五种宽度，共 46 项。
- 模拟触摸仅验证 CSS/DOM 规则，不能代替真实手机上的键盘、安全区、粘滞悬停和触摸手感验收。
- 本地集成截图 `artifacts/live-*.png` 被忽略；旧已发布截图仍明确是合成原型。

采集认证与浏览器访问控制是两个独立边界；此目录不提供管理员登录或前端隐藏式管理权限。
